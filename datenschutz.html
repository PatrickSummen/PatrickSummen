Overview

This website is a single, static page. It has no user accounts, no database, and no contact form that submits data to a server. The sections below describe exactly what does — and doesn't — happen with your data when you visit.

Hosting

This site is hosted by GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA; part of Microsoft Corporation). Like most web hosts, GitHub automatically records technical access data for security and operation purposes (e.g. IP address, browser type, date and time of access, referring page) in server log files. See GitHub's own privacy statement for details on how long this data is kept and how it is processed.

Fonts

This site only uses fonts already installed on your device. No font files are loaded from external servers, so no data is transmitted to a third party for this purpose.

Contact

The "Send an inquiry" button opens your own email application via a standard mailto link. Anything you choose to write is sent directly to the email address shown, using your own email provider — this website itself does not receive, store, or process that message.

Cookies

This site does not set or read any cookies.

Analytics

No analytics or tracking tool is currently in use. If one is added in the future (for example, a cookie-free, privacy-focused service such as Plausible or Fathom), this section will be updated to name the tool, describe what it records, and explain the legal basis for using it.

Your rights (GDPR)

If you are located in the EU/EEA, you have the right to:

  • request access to any personal data held about you,
  • request correction or deletion of that data,
  • request restriction of processing,
  • object to processing, and
  • request data portability.

You also have the right to lodge a complaint with a data protection supervisory authority. To exercise any of these rights, use the contact details above.

Changes

This policy may be updated from time to time to reflect changes to the site, its hosting, or applicable law.
